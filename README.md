# Overview
A money clicker game inspired by a cookie clicker. Clicking on the clickable money image 
will increase the amount of the money produced based on additional upgrades that is displayed on the screen. 

# Running

This project is a Node.js project using Vite. You can run it on the command
line using `npx`:

```bash
npm install
npx vite
```

And then open your web browser and go to the address printed out by Vite.
